# Журнал сессий

Дословные промпты обоих участников, по папке на человека. Пишется автоматически
хуком `UserPromptSubmit` (`.claude/hooks/log-prompt.sh`) — руками сюда ничего
не добавляется.

| Папка | Кто | Зона |
|---|---|---|
| `roman/` | roman_restov | движок холста: вид, жесты, сетка, узлы |
| `alfis/` | alfis | оболочка: обвязка, проекты, хранение, инспектор, клавиши |

## Настройка на новой машине

Хук берёт имя из переменной `DEV_NAME`. Без неё всё пишется в общую папку
`unknown/`, и при слиянии веток журналы конфликтуют — так и случилось
25 августа, пришлось разъединять задним числом.

Класть надо в `~/.zshenv`, **не** в `~/.zshrc`: хуки запускаются
неинтерактивной оболочкой, а `.zshrc` такая оболочка не читает.

```bash
echo 'export DEV_NAME=<ваше имя>' >> ~/.zshenv
```

Проверка, что дошло:

```bash
zsh -c 'echo $DEV_NAME'
```
