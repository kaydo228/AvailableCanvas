## Запуск

```bash
git clone <url> && cd prostor
npm install
npm run dev
```

Открыть <http://localhost:5173>. Бэкенда нет, данные хранятся в браузере.

| Команда | Что делает |
|---|---|
| `npm run dev` | режим разработки |
| `npm run build` | сборка |
| `npm run test` | юнит-тесты |
| `npm run e2e` | сквозные сценарии Playwright |
| `npm run typecheck` | проверка типов |
| `npm run lint` | Biome |
