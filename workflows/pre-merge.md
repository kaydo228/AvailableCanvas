# Workflow: подготовка ветки к merge

**Кто запускает:** оба, каждый в своей ветке.
**Когда:** перед каждым вливанием в `main` — в четверг вечером и в пятницу.
**Как запускать:** скопировать блок ниже в сессию Claude Code целиком.

---

## Промпт

```
Готовим мою ветку к вливанию в main. Иди строго по шагам, после каждого показывай
результат и не переходи дальше, пока предыдущий не зелёный.

1. npm run typecheck — если красное, чини.
2. npx biome check . — если красное, чини.
3. npx vitest run — если падает, разбирайся: тест врёт или код врёт. Не удаляй тест,
   чтобы он позеленел, я это замечу.
4. npx playwright test — если сценарий отваливается, скажи почему, не отключай его.
5. Пройди по критериям приёмки из docs/SPEC.md, раздел 10, но только по пунктам,
   которые относятся к моей зоне. По каждому — да или нет, без «вроде работает».
6. Запусти /code-review по диффу против main. Всё, что он нашёл на уровне корректности,
   почини. Замечания про вкус покажи мне списком, решать буду сам.
7. Запусти /simplify по тем же изменениям.
8. Собери git diff --stat против main и напиши, что в ветке изменилось, одним абзацем.
9. Допиши в REPORT.md раздел про эту ветку: что сделано, что не сделано, что пришлось
   переделать и почему. Особенно то, что не получилось — это то, что оценивают.

В конце дай вердикт одной строкой: готово к merge или нет, и если нет — что мешает.
```

---

## Чем доказывается выполнение

Каждый шаг оставляет след: вывод команды в сессии, раздел в `REPORT.md`, коммит с фиксами.
