# Что изменилось после ревью

Оба ревьюера отработали по два раунда. Их находки приняты почти целиком;
ниже — что именно меняет план.

## Принято и меняет реализацию

| Находка | Кто | Что делаем |
|---|---|---|
| Ломаная: сонаправленные стороны (обе `right`) не описаны | геометрия | добавлена четвёртая ветка маршрута — обход «наружу и вокруг» |
| Наконечники берут угол от хорды `from→to`, на ломаной и кривой смотрят не туда | оба | угол берётся из касательной **фактического маршрута** |
| `connectorPath(): number[]` не различает полилинию и Безье | оба | сигнатура структурная: `{ points, bezier }` |
| Контрольное плечо Безье при малой дистанции вырождается в константу 24 | геометрия | нижняя граница снижена до 12, множитель поднят до 0.5 |
| Нормаль свободного конца — деление на ноль при совпавших концах | геометрия | вырожденный случай отсекается до нормировки |
| Середина маршрута не определена алгоритмически | геометрия | по длине дуги: полилиния точно, Безье — по 24 отсчётам |

## Принято, но решается иначе, чем предлагал ревьюер

**Подпись НЕ режем.** Ревьюер интеграции предлагал срезать её первой:
из-за `exactOptionalPropertyTypes` и решения зоны B «панель никогда
не удаляет ключ» удалить `label` из модели нельзя, а критерий приёмки 7
этого требует.

Решение: **пустая подпись — это `label.value === ''`, а не отсутствие ключа.**
Не рисуется, не создаёт подложку, не мешает. Ключ в модели остаётся —
и это ровно то, что уже делает кнопка «Добавить подпись» в инспекторе.
Критерий 7 переформулирован: «пустая подпись не оставляет следов **на доске**».
В `CONTRACT-REQUESTS.md` уходит запрос напарнику: показывать «Убрать подпись»
как очистку значения, а не удаление ключа.

Причина, по которой не режем: подпись прямо заказана, а срезать её ради
одного критерия, который можно корректно переформулировать, — это подмена
задачи удобством исполнителя.

## Отдельно: исправление ложной записи

Ревьюер интеграции обнаружил, что **узкой подписки в `ConnectorView` нет**,
хотя коммит `54b8d79` и `DECISIONS.md` записали её как сделанную.

Проверено: подтверждается. `ConnectorView.tsx:57` читает `s.document`
целиком, `memo` нет. Причина — скрипт правки печатал «ok» независимо
от того, совпала ли строка замены; типы при этом сходились, потому что
файл остался валидным.

Входит в этот прогон отдельным шагом, запись в журнале решений будет
исправлена.

# План

## Шаг 1. `connectors/routing.ts` — маршруты

Новый файл. Экспорт:

```ts
export interface Route {
  points: number[];              // плоский массив для Konva
  bezier: boolean;               // 2 + 6k чисел, если true
  /** Касательная на концах: куда смотрят наконечники. */
  startTangent: WorldPoint;
  endTangent: WorldPoint;
}
export function connectorRoute(connector, document): Route | null
```

Внутри — три частных построителя: `straightRoute`, `elbowRoute`, `curveRoute`.
Наружу торчит только `connectorRoute`: единственная точка правды о маршруте,
ради которой всё и затевалось.

**Ломаная**, четыре ветки по взаимной ориентации сторон выхода и входа:

1. противоположные по горизонтали (`right`→`left`) — вертикальный разрез
   посередине между вылетами;
2. противоположные по вертикали — горизонтальный разрез;
3. перпендикулярные — одна точка перегиба;
4. **сонаправленные** (обе `right`) — обход: вылет, затем сдвиг наружу
   до дальней из двух фигур плюс запас, затем возврат.

Вылет 16 мировых единиц, ужимается до половины дистанции, но не меньше 4.

**Кривая:** контрольная точка отложена от якоря по нормали стороны на
`clamp(dist * 0.5, 12, 160)`. Возвращает 8 чисел и `bezier: true`.

**Вырожденные случаи** во всех трёх: дистанция меньше 1e-6 — прямая
из двух точек, `bezier: false`.

## Шаг 2. `connectors/labelPosition.ts` — середина маршрута

```ts
export function routeMidpoint(route: Route): WorldPoint
```

Полилиния: обход по длине дуги, накопление до половины суммарной длины,
линейная интерполяция внутри найденного сегмента. Нулевая длина сегмента
пропускается — это и есть защита от деления на ноль.

Безье: 24 отсчёта по `t`, ломаная из них, дальше тот же обход по длине.
Точность выше не нужна: подпись сдвинутая на пиксель не читается иначе.

## Шаг 3. `ConnectorView` — рендер и исправление подписки

Три правки в одном файле:

1. **узкая подписка** — селектор возвращает `Route`, сравнение через
   `useShallow`; `memo` на компоненте. Это исправление ложной записи,
   а не новая работа;
2. маршрут берётся из `connectorRoute`, `bezier` прокидывается во **все три**
   `<Line>` — тело, подсветку выделения и полосу захвата, иначе полоса
   захвата останется прямой и клик по кривой не поймается;
3. наконечники поворачиваются по `startTangent` / `endTangent`.

Осторожно с `useHookAtTopLevel`: подписка обязана стоять до любых ранних
возвратов, иначе `gate-stop.sh` завернёт работу.

только для чтения из инспектора, и это пишется в отчёт.
