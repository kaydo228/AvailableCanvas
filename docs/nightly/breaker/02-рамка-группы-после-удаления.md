# Гипотеза

`removeNodes` в сторе заканчивается вызовом `resyncGroups(state.document, expanded)`,
где `expanded` — список **только что удалённых** id. А `resyncGroups` начинает
с того, что берёт узел по id и смотрит его `groupId`:

```ts
const node = document.nodes[id];
const parent = node && node.type !== 'connector' ? node.groupId : undefined;
if (parent !== undefined) pending.add(parent);
```

Узла в `nodes` уже нет — `parent` всегда `undefined`, очередь пуста, цикл
не выполняется ни разу. То есть **пересчёт рамок после удаления не делает
ничего**: строка стоит, комментарий рядом обещает обратное.

`src/shared/store/board.ts:390` (`resyncGroups(state.document, expanded)`),
сам обход — `src/shared/store/board.ts:183`.

# Проверка

Проба: [`probes/02-stale-bounds.spec.ts`](probes/02-stale-bounds.spec.ts).

```bash
npx playwright test --config=docs/nightly/breaker/probes/playwright.config.ts 02-stale
```

## 02.1 — рамка не сжимается (НАХОДКА, воспроизводится стабильно)

Группа из трёх фигур: `a` (x=0), `b` (x=200), `c` (x=1000). Удалён `c`.

| | x | width |
|---|---|---|
| до удаления | 0 | 1120 |
| **после удаления `c`** | **0** | **1120** |
| ожидалось (a+b) | 0 | 320 |

Тест падает на `expect` — это ожидаемо, проба написана как обвинение.

## 02.2 — контрольный опыт: при движении ребёнка пересчёт работает

`moveNodes(['b'], 500, 0)` → рамка честно стала 820. Значит дело не
в `groupBounds` и не в `resyncGroups` как таковых, а именно в том, что после
удаления им передают несуществующие id.

## 02.3 — призрак уводит вид (следствие 01.1)

Группа из `a` (0,0) и `b` (5000,3000), обе удалены; на доске остаётся одна
фигура 100×100 в начале координат. `zoomToFit()` даёт

```json
{"x":40,"y":57.6875,"zoom":0.178125}
```

то есть вид подогнан под **рамку призрака 5120×3080**, а не под единственный
видимый узел. На экране — почти пустой холст с точкой в углу, и человек
не понимает, почему «показать всё» показывает ничего. `boundsOf` перебирает
`document.order`, а призрак из `order` не удалялся.

Тот же путь у экспорта в PNG: `export/lib/bounds.ts` считает по составу
документа, и пустая группа расширяет картинку на несколько тысяч пикселей
пустоты.

# Чем это опасно

Рамка группы — не только подсветка. По ней работают `zoomToFit`,
`zoomToSelection`, экспорт, панель свойств (показывает размер) и
`resizeNode` для внешней группы. Устаревшее значение живёт в документе
и **сохраняется в IndexedDB**, то есть переживает перезагрузку: пересчитать
его нечем, пока пользователь не подвинет хоть одного ребёнка.

Починка на вид однострочная — считать родителей **до** удаления и передавать
их, а не удалённые id, — но она за пределами задания: не чиню.
