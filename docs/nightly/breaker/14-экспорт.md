# 14.1 — PNG размером 6168×4128, на котором ничего нет (НАХОДКА-следствие)

Собрал группу из двух фигур, разнесённых на 6000×4000, и удалил обе —
осталась призрачная группа из итерации 01 с рамкой во всю бывшую площадь.
Экспорт «вся доска»:

```json
{"ok":true,"width":6168,"height":4128,"bytes":656386}
```

Шестьсот килобайт абсолютно пустого PNG.

Добавил рядом обычную фигуру 120×80 и снял ещё раз — размер картинки
не изменился: **6168×4128**, и содержимое в ней занимает 0.06 % площади.
Экспортировать доску, на которой невидимо живёт мёртвая группа, значит
получать картинку вокруг пустого места, и понять почему невозможно —
источник раздувания на экране не виден.

Это следствие находок 01.1 и 02.1, а не отдельный дефект, но именно здесь
оно бьёт по пользователю сильнее всего.

# 14.2 — вырожденные случаи PNG: отбиты честно

| доска | результат |
|---|---|
| пустая | отказ: «На доске пусто — нечего сохранять.» |
| один коннектор нулевой длины | картинка 48×48, без исключений |

# 14.3 — узел 1 000 000 × 1 000 000

```
1×: отказ — «Область 1000048×1000048 пикселей слишком велика для браузера
    (предел 16384). Возьмите множитель поменьше или экспортируйте выделенное.»
2×: то же с удвоенными числами
```

Предел проверяется до растеризации, молчаливой пустой картинки нет —
ровно то, о чём предупреждает комментарий в `exportPng.ts`. **Не сломалось.**

# 14.4 — круг «экспорт JSON → импорт»

Доска с группой, повёрнутым на 33° узлом и коннектором между участниками
группы: выгрузил в файл, импортировал файл обратно.

```
тост: «Доска «Круг» открыта»  (ни одной починки)
после импорта: shape, shape, connector, group
```

Круг замкнулся без потерь и без предупреждений. **Не сломалось.**
