---
title: "Итерация 13 — окно между сменой адреса и монтированием холста"
---

Холст с 28 августа грузится через `React.lazy`. Меня интересовало окно
между сменой адреса и монтированием: что в нём делают клавиши, уход назад
и метания по истории. Чтобы окно стало широким, запрос куска `CanvasScreen`
притормаживается через `page.route` на 2.5–3 секунды.

Проба: [`probes/13-lazy-route.spec.ts`](probes/13-lazy-route.spec.ts).

```bash
npx playwright test --config=docs/nightly/breaker/probes/playwright.config.ts 13-lazy
```

**Сломать не удалось.**

# 13.1 — клавиши в окно ожидания

В момент, когда адрес уже `/p/…`, а холста ещё нет, нажаты подряд
`Delete`, `Cmd+A`, `Cmd+D`, `Cmd+G`, `Cmd+Z`, `Escape`. После монтирования:

```
узлы: ["a","b"]   выделение: []   нарушений нет   ошибок нет
```

Ни одна клавиша не сработала вхолостую по пустому документу и не удалила
ничего. Обработчики живут внутри холста и до его монтирования не подписаны —
именно так и надо.

# 13.2 — уход назад до монтирования

Ушёл назад через 200 мс после начала перехода, дождался, пока кусок всё-таки
приедет. Оказался на `/`, документа в сторе нет (`null`), ошибок нет.
Главное — **база не затёрта**: вернувшись на доску, вижу оба узла на месте.
Это неочевидный исход: размонтирование `useAutosave` в cleanup делает
принудительный `flush`, и он мог бы записать пустой или неполный документ.
Не записал.

# 13.3 — метания по истории

Восемь циклов «доска → список → доска» с шагом 60 мс через `pushState` +
`popstate`. Узлы целы, нарушений нет, консоль чиста, утечки обработчиков
по счётчику ошибок не видно.

# 13.4 — адрес несуществующего проекта

`/p/такого-нет` → редирект на `/`, без падения и без белого экрана.
Единственная мелочь: **молча**. При удалении проекта из списка приложение
показывает «Проект уже удалён», а по прямой ссылке на несуществующий
проект человек просто оказывается на списке без объяснений. Косметика.
