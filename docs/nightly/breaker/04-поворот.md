Здесь **ничего сломать не удалось**, и это стоит записать подробно:
поворот — единственная из четырёх новых фич, которая выдержала всё,
что я в неё бросил.

# 04.1 / 04.2 — обратимость

Группа из двух фигур, `a` в (0,0), `b` в (300,100).

| | a | b |
|---|---|---|
| исходно | (0, 0) | (300, 100) |
| после `rotate(90)` | (300, −120) | (200, 180) |
| после `rotate(0)` | **(0, 0)** | **(300, 100)** |

То же на 45°: после возврата координаты совпадают с исходными **точно**,
не «примерно» — ни накопления ошибки, ни дрейфа центра. Именно этого
я и ждал не увидеть: рамка группы осевая, при повороте на 45° она
раздувается, и наивная реализация теряет центр.

# 04.3 — накопление ошибки

Сто последовательных вызовов `rotateNode(g, 1..100)` против одного
`rotateNode(g, 100)` на той же исходной конфигурации:

```
по градусу  : a (335.099, −101.181)  b (184.524, 176.896)
сразу на 100: a (335.099, −101.181)  b (184.524, 176.896)
```

Совпадение до третьего знака. Дрейфа нет, потому что угол хранится
абсолютным, а дельта считается от него.

# 04.4 — мусорные углы

| подано | стало |
|---|---|
| 720 | 0 |
| −0 | 0 (именно `+0`, `Object.is(r, -0) === false`) |
| −720 | 0 |
| 1 000 000 000 | 280 |
| `NaN` | 0 |
| `Infinity` | 0 |
| 359.9999999 | 359.9999999 |
| `updateNode({rotation: 370})` | 10 |

Минус-ноль убран специально (`normalizeAngle` дописывает `+ 0`), путь
через панель свойств нормализуется тоже. Нарушений инвариантов нет,
консоль чистая.

# 04.5 — растяжение группы с повёрнутым ребёнком (мелкое расхождение)

Группа из повёрнутой на 45° фигуры и обычной. Попросил рамку
`{x:0, y:0, width:100, height:50}`, получил `x:−3.84, width:103.84`.

Причина понятна и описана в самом коде: дети масштабируются по своим
`x/y/width/height`, а рамка потом пересчитывается по **углам повёрнутого**
ребёнка, которые от масштабирования не сжимаются пропорционально.
Расхождение около 4 % и не накапливается при повторных растяжениях.

Это косметика (рамка чуть больше протянутой мышью), но при сильном
сжатии группы с повёрнутым содержимым разница станет заметной.
