Две находки я вывел частично из чтения кода, и обе надо было подтвердить
тем путём, которым ходит человек. Проба:
[`probes/15-verify.spec.ts`](probes/15-verify.spec.ts).

```bash
npx playwright test --config=docs/nightly/breaker/probes/playwright.config.ts 15-verify
```

# 15.1 — `Cmd+D` настоящей клавиатурой (подтверждает 03.1)

Не `duplicateNodes` из консоли, а нажатие `Cmd+D` (и `Ctrl+D`) на выделенной
группе:

```
типы в документе: shape, shape, connector, group, group, shape, shape
коннекторов: 1 (было 1)
```

Копия группы действительно приезжает без связи. Находка 03.1 достижима
штатной клавишей, а не только через стор.

# 15.2 — клик по узлу с односторонней связью (подтверждает 07.3)

Документ, где `b.groupId = 'g'`, но `g.children = ['a']`. Прогнал через
`selectionForClick` — ту самую функцию, которую зовёт холст на клик:

```
клик по b даёт выделение: ["g","a"]
клик по a даёт выделение: ["g","a"]
```

Щёлкнув по `b`, человек получает выделение, **в котором `b` нет**.
Дальше рамка, перетаскивание, `Delete` и панель свойств работают
не с тем, по чему щёлкнули. Находка 07.3 подтверждена.

# Заодно проверено и не сломалось

- Шрифт: подписи на холсте по-прежнему просят `fontFamily="Inter, …"`
  (`ShapeView`, `StickyView`, `ConnectorLabel`, `TextOverlay`), а в
  `public/fonts` с 28 августа лежат **Golos Text и IBM Plex Mono** —
  `Inter` в проекте нет вовсе. Это известный дефект из задания, но деталь
  новая: дело не в том, что шрифт не подключили, а в том, что холст просит
  шрифт, которого в проекте не существует, и текст на доске рисуется
  системным, расходясь с панелями. Одной строкой, как и договаривались.
