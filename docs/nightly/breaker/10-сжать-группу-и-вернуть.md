# 10.1 — содержимое группы разрушается необратимо (НАХОДКА)

**Что сделал.** Группа из трёх одинаковых фигур 120×80, расставленных
по доске. Растянул рамку группы в 10×10 и следом вернул в исходные 1120×480 —
то есть сделал ровно то, что делает человек, дёрнувший угловую ручку
внутрь и обратно, не отпуская мышь.

**Что ожидалось.** Группа вернулась в исходный размер — значит и содержимое
вернулось: три фигуры 120×80 на своих местах.

**Что произошло.**

```
исходно         : a 0,0 120×80    b 500,0 120×80    c 1000,400 120×80
сжали до 10×10  : a 0,0 8×8       b 4.5,0 8×8       c 8.9,8.3 8×8
вернули 1120×480: a 0,0 529×235   b 295,0 529×235   c 591,245 529×235
рамка           : 1120×480 — «верная»
```

Три аккуратные карточки превратились в три перекрывающихся плиты
в полэкрана каждая. Рамка группы при этом честно вернулась к 1120×480,
так что по рамке ничего не заметно — заметно по содержимому.

**Почему.** На сжатии каждый ребёнок проходит через `clampSize`
с полом `MIN_NODE_SIDE = 8`. Настоящий масштаб был ≈0.009, применённый —
0.067 у одних детей и другой у других, потому что пол сработал у всех
по-разному относительно исходного размера. Информация о пропорции
потеряна безвозвратно; обратное растяжение считает масштаб от уже
искажённых границ.

Комментарий в `resizeNode` этот компромисс называет прямо: «при сильном
сжатии пропорция мелкой фигуры важнее, чем то, что её нельзя поймать мышью».
Но следствие — необратимость целого жеста — там не учтено: пользователь
не «сжимает и оставляет», он дёргает ручку туда-сюда в пределах одного
перетаскивания, и каждый промежуточный кадр уже уничтожил пропорции.

**Воспроизводится стабильно.** Спасает только отмена (`Cmd+Z`), если
человек догадается, что произошло.

# 10.2 — контрольный опыт без упора в минимум

Растянул ту же группу в 1000 раз и вернул обратно:

```
исходно: a 0,0 120×80   b 500,0 120×80
×1000  : a 0,0 120000×80000   b 500000,0 120000×80000
обратно: a 0,0 120×80   b 500,0 120×80
```

Точное возвращение. То есть математика масштабирования верна, ломает
именно зажим по минимуму.

# 10.3 — растяжение группы с нулевой высотой рамки

Сжал группу в высоту 0, затем растянул в 500. Ошибок нет, деления на ноль
нет (`scaleY = 1` при нулевой стороне, как и написано в коде), дети получили
высоту 500 каждый. Формально корректно. **Не сломалось.**
