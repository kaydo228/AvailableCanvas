# A-4 · Среда. Фигуры, текст, стикеры

```
Сегодня кладём объекты на холст. Работай по скиллу canvas-node-type, он для этого
и написан.

Три параллельных агента, по типу на каждого:
1) фигуры: прямоугольник, скруглённый, эллипс, треугольник, ромб. Создание протяжкой,
   Shift — пропорции. И главное: у фигуры есть подпись внутри, по двойному клику,

   обычный textarea абсолютом поверх канваса, координаты считай из мировых через

   Не пытайся редактировать средствами Konva, ты потеряешь на этом полдня;
3) стикеры: квадрат с заливкой и текстом, палитра из шести цветов, текст ужимается
   если не влезает.

Каждому агенту — только своя папка. Когда соберёшь всё вместе, дай мне ссылку, я
посмотрю глазами, и не рапортуй «готово», пока сам не откроешь и не потыкаешь.
```

# A-6 · Среда вечер. Выделение

```
Выделение и трансформации. Бери Transformer из Konva, руками ручки не рисуй.

Что должно работать:
— клик выделяет, Shift+клик добавляет, клик по пустому снимает;
— протяжка инструментом «Выбор» по пустому месту рисует рамку и выделяет всё, что
  она задела;
— восемь ручек размера плюс ручка поворота;
— перетаскивание работает и для одного объекта, и для группы выделенных;
— стрелки двигают на пиксель, Shift+стрелки на десять;
— Delete удаляет, Cmd+A выделяет всё;
— ] и [ двигают по слоям, с Cmd — в самый верх и в самый низ.

Выделение рисуй на отдельном слое Konva, не в общем — иначе при каждом клике будет
перерисовываться вся доска, а мне потом тысячу узлов тянуть.
```
