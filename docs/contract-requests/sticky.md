# Стикер → инспектор

**2026-08-25 · A → B**

Тип `StickyNode` уже в `Node`. Поля: `fill: string`, `text: TextStyle`
плюс общие из `BaseNode`.

## Что нужно в панели

| Поле | Элемент управления |
|---|---|
| `fill` | **палитра из шести цветов**, не произвольный пикер |
| `text.align` | три кнопки выравнивания |
| `text.bold` | переключатель |
| `opacity` | ползунок 0–100 % |

Палитра лежит в `src/features/canvas/nodes/stickyPalette.ts`, экспорт
`STICKY_PALETTE` — импортируй её, свой список цветов не заводи.

## Важно: цвет текста не редактируется отдельно

`text.color` у стикера **связан с заливкой**: в палитре для каждой заливки
лежит подобранный читаемый цвет текста (`StickyColor.text`). Отдельного
поля цвета текста в панели быть не должно — иначе пользователь поставит
жёлтый на жёлтом.

При смене заливки панель обязана обновлять и `text.color` — одним вызовом:

```ts
updateNode(id, { fill: color.fill, text: { ...node.text, color: color.text } });
```

Есть готовый хелпер `stickyTextColor(fill)` в том же модуле.

## Кегль в панели не показываем

Кегль стикера подбирается автоматически под рамку (`fitFontSize`), поле
`text.fontSize` работает как **верхняя граница**, а не как итоговый размер.
Если показывать его как «размер шрифта», пользователь поставит 48, увидит 14
и решит, что сломано. Либо не показывать вовсе, либо подписать
«максимальный размер».

## При множественном выделении

Общее с фигурой и текстом: `opacity`, порядок слоёв, выравнивание.

## Действия стора

`updateNode`, `updateNodes`. Новых не требуется.
