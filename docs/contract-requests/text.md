# Текстовый узел → инспектор

**2026-08-25 · A → B**

Тип `TextNode` уже в `Node`. Поля: `text: TextStyle`, `autoWidth: boolean`
плюс общие из `BaseNode`.

## Что нужно в панели

| Поле | Элемент управления |
|---|---|
| `text.fontSize` | число со стрелками, шаг 1, диапазон 8–144 |
| `text.color` | палитра + произвольный цвет |
| `text.align` | группа из трёх кнопок: влево, по центру, вправо |
| `text.bold`, `text.italic` | две кнопки-переключателя |
| `text.lineHeight` | число, шаг 0.1, диапазон 0.8–3 |
| `autoWidth` | переключатель «ширина по содержимому» / «фиксированная» |
| `opacity` | ползунок 0–100 % |

## При множественном выделении

Общее с фигурой и стикером: `opacity`, порядок слоёв, цвет текста, кегль,
выравнивание. `autoWidth` — только у текста, при смешанном выделении скрывать.

## Действия стора

`updateNode`, `updateNodes`. Новых не требуется.

## На что обратить внимание

При переключении `autoWidth` из false в true ширина узла перестаёт быть
значимой, но остаётся в модели. Панель не должна показывать поле ширины
как редактируемое, пока `autoWidth` включён, иначе значение выглядит рабочим,
а ни на что не влияет.
