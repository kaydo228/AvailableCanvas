# Вторник 25 августа — движок вида

**Цель дня:** пустой бесконечный холст, по которому можно летать, и он не тормозит.

| Блок | Что делаем |
|---|---|
| Утро | Три субагента: (1) viewport и преобразование координат, (2) панорамирование и зум через `@use-gesture/react`, (3) фоновая сетка с зависимостью плотности от зума |
| День | Сборка результатов, hit-test, слои Konva: статика отдельно, выделение отдельно |
| Вечер | Написать скилл `canvas-node-type` через `/skill-creator` |

**Определение готовности:**

- зум по `Cmd`+колесо идёт **к курсору**, а не к центру — проверить руками, это самая
  частая ошибка и её сразу видно;
- `Space`+перетаскивание и средняя кнопка панорамируют;
- зум ограничен 10–400 %, `Cmd+0` возвращает 100 %;
- в консоли нет предупреждений React про ключи и вложенность.

**Коммиты:** `feat(engine): вьюпорт и координаты`, `feat(engine): панорамирование и зум`,
`feat(engine): сетка`, `chore: скилл canvas-node-type`

# Среда 26 августа — объекты

**Цель дня:** на холст можно положить всё четыре типа и подвигать.

| Блок | Что делаем |
|---|---|
| Утро | Три субагента: (1) фигуры пяти видов + подпись внутри, (2) текстовый узел с оверлеем `<textarea>`, (3) стикеры |
| День | Изображения: кнопка, перетаскивание файла, вставка из буфера; blob в IndexedDB через API, который дал B |
| Вечер | Выделение: клик, `Shift`+клик, рамка протяжкой, `Transformer` Konva |

**Определение готовности:**

- каждый из пяти типов создаётся, двигается, меняет размер, поворачивается, удаляется;
- двойной клик по фигуре открывает ввод подписи, текст центрируется и переносится;
- пустой текстовый блок при потере фокуса исчезает сам;
- картинка вставляется с сохранением пропорций, вписанная в 600 px;
- порядок слоёв меняется по `]` и `[`.

**Приём для текста:** `<textarea>` абсолютно позиционируется поверх канваса, координаты
считаются из мировых через трансформ вьюпорта, по `blur` значение уезжает в узел.
Не пытайся редактировать текст средствами Konva, их там нет.

**Коммиты:** по одному на тип узла, каждый — по чеклисту скилла `canvas-node-type`

# Четверг 27 августа — коннекторы

**Самый тяжёлый день недели.** Закладывай его целиком, ничего другого не планируй.

Идти строго от простого к сложному, каждый этап — рабочее состояние, которое не стыдно
показать, если следующий не успеется:

1. Прямая линия между двумя свободными точками. Наконечники: нет, стрелка, точка.
2. Привязка конца к фигуре: подсветка четырёх якорей при наведении, `anchor: 'auto'`
   выбирает сторону по взаимному положению центров.
3. **Пересчёт при перемещении и изменении размера привязанной фигуры.** Ключевой пункт,
   без него диаграмм нет.
4. Отвязка концов при удалении фигуры: линия остаётся, конец фиксируется в последней
   вычисленной точке. Приложение не падает.
5. Ломаная под прямым углом.
6. Кривая Безье.
7. Подпись на линии.

Пункты 5–7 срезаются первыми, если не успеваешь. Пункты 1–4 не срезаются.

**Вечером — ночной прогон.** Запусти `workflows/nightly-run.md` на коннекторах перед сном.
Утром читаешь отчёт, а не диалог.

**Определение готовности:** критерии приёмки 4, 5, 6 из раздела 10 ТЗ проходят.

доски, две вкладки с одним проектом одновременно, отмена сразу после загрузки страницы.

**Определение готовности:** NFR-01 замерен реальной цифрой, а не на глаз. Все находки
ломателя — в `REPORT.md`, отсортированные по опасности, с пометкой «починено» или
«оставили и почему».
