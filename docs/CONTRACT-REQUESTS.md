# Запросы по контракту между зонами

Зона A (движок холста) пишет сюда, что нужно от зоны B (оболочка), и наоборот.
Смысл — чтобы «мне нужно поле в инспекторе» не терялось в переписке.

Правки `shared/types` и `shared/store` делаются вдвоём, коммитом с префиксом
`contract:`.

---

## 2026-08-25 · A → B · `canvasSize` в сторе

Добавил в стор `canvasSize: Size` и `setCanvasSize(size)`. Пишет `CanvasStage`
через `ResizeObserver`, читают `zoomToFit` и `zoomToSelection`.

**Что нужно от тебя:** подтверди, что не мешает. Если в оболочке уже есть своё
измерение размеров — скажи, сведём в одно место, два источника размера
разъедутся при первом же ресайзе.

**Статус:** ждёт подтверждения.

---

## 2026-08-25 · A → B · узлы холста

Три типа узлов реализованы, запросы по инспектору лежат отдельными файлами,
чтобы не мешать друг другу:

| Тип | Файл | Главное |
|---|---|---|
| Фигура | [contract-requests/shape.md](contract-requests/shape.md) | открытый вопрос про сброс `dash` и `cornerRadius` |
| Текст | [contract-requests/text.md](contract-requests/text.md) | поле ширины прячется при `autoWidth` |
| Стикер | [contract-requests/sticky.md](contract-requests/sticky.md) | цвет текста связан с заливкой, кегль — верхняя граница |

**Статус:** ждёт подтверждения.
