> поэтому PDF идёт **сверх** обязательного, как оформление. Это дешёвый плюс: полчаса.

# В плюс — берём столько, сколько успеем

Отсортировано по отношению «баллы к затраченному времени». Сверху то, что окупается лучше.

| Бонус | Сколько стоит | Чем закрываем | ✓ |
|---|---|---|---|
| **Команда** | бесплатно | двое, роли в `README.md` | ☐ |
| **Журнал сессий** | бесплатно | хук `log-prompt.sh` пишет `sessions/` сам | ☐ |
| **Честность** | бесплатно, повышает оценку | раздел «что не сработало» в `REPORT.md` | ☐ |
| **Переход на Git** | бесплатно | история веток, PR, коммиты | ☐ |
| Отчёт по инструментам | 30 мин | промпт S-6 | ☐ |
| Изоляция с доказательством | 40 мин | промпты S-2 и S-3, вывод отказа | ☐ |
| Замер последовательно/параллельно | 40 мин | промпт A-12, таблица в `REPORT.md` | ☐ |
| Worktrees + merge | 1 час | промпт S-1, `git worktree list` в истории | ☐ |
| Инъекция на двух моделях | 1–1,5 часа | промпт S-4, таблица 4×2 | ☐ |
| Оптимизатор контекста / индекс | 1–2 часа | необязательно, берём последним | ☐ |

**Не берём:** межролевая команда — нас двое фронтов, роли одинаковые. Этот плюс
недоступен честным путём, выдумывать себе чужую роль не стоит.

# Критерии оценки и что им отвечает

| Критерий из задания | Что смотрят | Наш ответ |
|---|---|---|
| **Работает** | запускается по инструкции, без «допишите тут своё» | `README.md` проверен на чистой папке |
| **Агенты запускались** | видно, что работа делалась субагентами | `sessions/` с дословными промптами, где видны команды на параллельный прогон |
| **Workflow есть** | приложен и применим к реальной задаче | два скилла, которыми реально пользовались по 4–5 раз за неделю |
| **Оформление** | текстовый результат как читаемый PDF | `docs/SPEC.pdf` |
| **Честность** | прямо сказано, что не сработало | `REPORT.md` §«Что не получилось», плюс дырявый `guard-bash.sh` описан как есть |
| **Плюсы** | команда, worktrees, изоляция, инъекция, инструменты, Git | таблица выше |
